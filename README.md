# Patas Livres

Site institucional estático do projeto Patas Livres — cuidado animal, dignidade e ressocialização.

## Executar localmente

Abra `index.html` em um navegador ou sirva a pasta com qualquer servidor estático. O site não depende de etapa de build.

## Estrutura

- `index.html`: conteúdo semântico e seções do site
- `styles.css`: identidade visual, layout responsivo e estados de interação
- `script.js`: carrossel acessível e menu móvel
- `assets/`: logotipo aprovado, fotos fornecidas para apresentação e ícone rasterizado do WhatsApp

## Observações de conteúdo

As ações são apresentadas como previstas no projeto. O número de aproximadamente 30 gatos é uma estimativa informada pela organização. A possível remição de pena é descrita como uma possibilidade em estudo, sujeita à legislação e à autorização das autoridades competentes.
